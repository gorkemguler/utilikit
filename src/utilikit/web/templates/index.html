Usage examples

Copy, paste, go. No SDK, no auth needed by default.

Domain WHOIS 
curl 'localhost:8400/v1/whois/domain?domain=example.com'

returns: registrar, dates, nameservers, DNSSEC status

DNS records 
curl 'localhost:8400/v1/dns/records?name=example.com&types=A,MX,TXT'

returns: records per requested type, with TTLs

Screenshot 
curl -o shot.png 'localhost:8400/v1/screenshot?url=https://example.com&full_page=true'

returns: full-page PNG, as raw bytes

Multi-hash 
curl localhost:8400/v1/hash \
  -H 'content-type: application/json' \
  -d '{"text":"hello","algorithms":["sha256","blake2b"]}'

returns: the computed digest for each algorithm

QR code 
curl -o qr.svg 'localhost:8400/v1/qr?text=https://example.com&format=svg'

returns: the QR code image, as SVG or PNG

Random password 
curl 'localhost:8400/v1/password?length=24&symbols=true'

returns: the password and an estimated crack time
